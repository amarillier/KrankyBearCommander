   Utility…/Disk Management… Eject is hidden for the boot volume, detected

   /Volumes with its own (possibly renamed) entry, which a plain "/" check

   auto-select a specific drive — there's no reliable, safe cross-platform
   way to target a destructive operation like that.

   elevation if done via the "obvious" raw volume lock/dismount/eject

   than Explorer's own (no elevation needed). Ejects via the same
   Shell.Application COM automation Explorer's own right-click Eject uses
   instead, avoiding that entirely.

   collision), so a rejected attempt's settings aren't lost either.
✨ NEW Multi-Rename Tool deselects everything after a successful rename,
   rather than leaving a confusing leftover selection: since selection is
   tracked by name, a file that got renamed silently fell out of it while
   everything else stayed selected. A rejected batch leaves the selection
   alone, since you'll likely want to retry it as-is.

   fit its column, same as real file managers.
