✨ NEW Change Attributes… (right-click / File menu / F9 popup) batch-edits
   the current selection (or just the cursor row) and the modified date/
   time (a "Now" button, or type your own). What's offered depends on the
   platform: Windows gets Read-only/Hidden/Archive/System, its own
   attribute bits; macOS/Linux get full POSIX permissions instead — Owner/
   Group/Other × Read/Write/Execute, the same model chmod/Finder's own
   Info panel use — plus Hidden on macOS specifically (Linux has no real
   "hidden" attribute, only a leading-dot filename convention, so it isn't
   offered there; Archive/System have no equivalent outside Windows at
   all). Every one of these is Unchanged/Set/Clear rather than a plain
   toggle, so a mixed selection can leave files that already differ alone
   instead of forcing them all to one value. "Recurse subdirectories"
   applies throughout a folder's tree — except Windows' Read-only
   specifically, which only ever applies to files, never directories
   themselves (clearing a directory's own write bit on macOS/Linux would
   block adding, removing, or renaming anything inside it, including
   undoing the change again later, a far more disruptive lock than
   "read-only" means for a folder on Windows); the macOS/Linux permission
   grid has no such exemption — reaching for full chmod-style control
   means real chmod -R-style behavior, directories included. Local files
   only, same as Multi-Rename Tool — not offered against an archive,
   Listbox view, or connection tab.
✨ NEW Properties (Windows) / Get Info (macOS) on the right-click menu —
   opens the OS's own native file-properties window, the same one
   Explorer's/Finder's own right-click menu opens. Not offered on Linux,
   which has no equivalent universal command across desktop environments.
✨ NEW Application Launcher (File menu / F9 popup, or the toolbar button
   next to 🖥 Connections) — a plain, alphabetized, filterable list of
   applications you add; click one to launch it detached (it keeps
   running even after Commander quits — no orphan/zombie child left
   behind). Drag an application file in for a quick Name+Command add
   (Start In defaulted to its own directory), or use the Add… button for
   the full form: Parameters, Start In, and Environment Variables too
   (ideas borrowed from ../KrankyBearExecutor, minus its comments/alias
   field and multi-app groups — not wanted here) — each entry's Edit…
   button opens the same form later, so a quick drag-added entry can get
   these filled in afterward. Deliberately simpler than TotalCmd's icon
   toolbars otherwise (floated as a "someday" idea earlier, now built this
   way instead): a plain text list, no icons, no drag-positioned toolbar
   buttons, no secondary grouped bars.
✨ NEW Export Settings… / Import Settings… (File menu / F9 popup) bundles
   everything that persists across launches — general preferences (window
   size, panel colors, hidden-files/drive-bar visibility, column widths,
   7-Zip path, Multi-Rename's remembered pattern, ...), Favorites, Editors,
   Connections, the Application Launcher list, and window/tab layout —
   into one zip, so moving settings to another install is a single file
   instead of hunting through several OS-specific locations. The update-
   checker's own cache is deliberately excluded — it's cached state, not a
   real setting. Keychain-stored secrets (connection passwords, SSH key
   passphrases, FileAgent pre-shared keys) are never included — re-enter
   those after importing, and expect Application Launcher entries/SSH key
   paths not to carry over meaningfully to a different machine or OS.
   Import writes the files immediately but doesn't take effect live —
   Fyne keeps its own preferences in memory for the app's whole lifetime
   and rewrites them from that on every quit, which would otherwise
   silently undo an import — so it offers to quit right then instead;
   reopen Commander afterward to see the imported settings.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✨ NEW Drag files OUT of a pane straight onto Finder/Explorer, another app
   (e.g. Slack), or the opposite pane — the reverse of drag-IN (macOS and
   Windows; Linux still to come). Drags whatever's currently selected (or
   the cursor row), same rule as Copy/Multi-Rename. A native Cocoa drag
   session on macOS, not osascript; on Windows, real OLE
   IDropSource/IDataObject COM objects via DoDragDrop, not a PowerShell
   subprocess.
✨ NEW Multi-Rename Tool (Ctrl+M, right-click menu, File menu/F9 popup) —
   TotalCmd-style batch rename with a pattern language ([N] name, [N1-3]
   name characters 1-3, [E] extension, [C]/[C:start]/[C:start,step]/
   [C:start,step,width] counter), whole-name case conversion (UPPERCASE/
   lowercase/Title Case/Sentence case), and find/replace (plain text or
   regex) — with a live old→new preview for the whole selection before
   anything changes on disk. Same-batch collisions (e.g. swapping two
   files' names) are handled safely via a two-phase rename; anything that
   would collide with an unrelated existing file is refused up front.

Version 0.4.0 - July 24, 2026
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✨ NEW Double-click a .zip to browse straight into it, exactly like a real
   directory — tabs, sorting, Full/Brief view, checkboxes/shift-click/
   Select All, and the status line all just work. ".." at the archive's own
   root steps back out to the real folder it lives in.
✨ NEW F5 inside an open archive extracts the selection (or just the
   cursor row) to the opposite pane's directory instead of copying, with
   the same progress dialog and Overwrite/Skip/Rename/Cancel handling as a
   real Copy. A stripped-down right-click menu offers the same as
   Extract to Opposite Pane, plus Open and View.
✨ NEW F3 View on a file already inside an open archive extracts it to a
   temp copy first, then opens the normal viewer — and F3 on a .zip file
   you haven't browsed into yet offers a lightweight picker to preview a
   single member without fully browsing in.
✨ NEW F4 Edit, Move/Rename, MkDir, and Delete refuse with a clear
   "Read-Only Archive" dialog when browsing inside a .zip, instead of
   failing confusingly (or, for F4, silently opening an empty file)
   against paths that don't really exist on disk.
✨ NEW Inline rename: click an already-selected/cursor row's name again
   (slower than a double-click) to edit it in place, in either view mode.
   Enter commits, Escape or clicking away cancels; the extension is hidden
   during editing and silently reattached unless you type your own.
✨ NEW Check for Updates is now in the F9 popup too, alongside Help/About.
✨ NEW Create Symbolic Link…'s dialog is bigger and easier to use, defaults
   to "link-<name>" alongside the source in the tab's own directory (not
   the opposite pane), and pre-selects the name so retyping it is a single
   keystroke.
🐛 FIX Clicking the F9 Menu button (as opposed to pressing the F9 key)
   left the popup unable to close via Escape or a second F9 press — it
   needed an extra click just to dismiss. The button was clearing keyboard
   focus right after showing the popup, undoing the focus Fyne had just
   given it.
✨ NEW Ctrl+C / ⌘C copies the selection (or cursor row) to the OS clipboard
   as real files — Paste into Finder/Explorer/Nautilus copies them there
   for real, same as copying the files themselves would. Ctrl+V / ⌘V does
   the reverse: copies whatever files are on the OS clipboard (e.g. from
   Ctrl+C on files in Finder/Explorer) into the active pane's directory.
   Also on the right-click menu (Copy / Paste — Paste always targets the
   right-clicked row's own directory) and File menu/F9 popup (Copy/Paste).
   Implemented as native platform code (Cocoa on macOS, Win32 on Windows,
   xclip/wl-copy on Linux) rather than osascript/PowerShell, which are
   automation engines security tooling commonly watches for.
✨ NEW Drag files from Finder/Explorer/Nautilus and drop them onto a pane
   to copy them in, at that pane's active tab's current directory.

Version 0.3.0 - July 23, 2026
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✨ NEW Right-click context menu on any file/directory row: Open, Open With
   (your configured F4 external editors), Duplicate, Move to Trash, and
   Reveal in Opposite Pane (same tab or a new one) — plus Add to Favorites
   for directories.
✨ NEW Show Hidden Files toggle (View menu / F9 popup) — dotfiles are
   hidden by default; the choice persists across launches.
✨ NEW Directories (and "..") get their own configurable text color in
   Panel Colors, distinct from ordinary files.
✨ NEW F7 New Folder prefills the cursor row's name so retyping part of it
   is quick instead of typing a name from scratch.
✨ NEW Swap Panes and Manage Editors… are now on the View/File menus, not
   just the F9 popup.
✨ NEW Shift-click range-selects between the anchor and clicked row; Ctrl
   (⌘ on macOS)-click toggles just that row — an alternative to the
   selection checkboxes for selecting many items at once.
✨ NEW Select All (Ctrl+A / ⌘A) and Deselect All (Ctrl+Shift+A / ⌘⇧A),
   plus a Select All/Deselect All toolbar button next to Favorites.
✨ NEW Right-click Compress → To .zip (always available) or To .7z (when a
   7z/7za/7zz binary is found on PATH, or pointed at via File → 7-Zip
   Binary Path… for one that isn't) — compresses the current selection (or
   just the cursor row) into an archive alongside the source.
✨ NEW Right-click Copy Name / Copy Path puts the item's name or full path
   on the clipboard as text.
✨ NEW Right-click Create Symbolic Link… creates a symlink to the item,
   defaulting to the opposite pane's current directory.
✨ NEW Right-click Reveal in File Manager opens Finder/Explorer (or the
   Linux desktop's file manager) with the item selected.
✨ NEW Search… (File menu / F9 popup / pane toolbar 🔍) recursively
   searches the active tab's directory by name or wildcard pattern;
   picking a match opens its location in a new tab with the file selected.
✨ NEW F2 Refresh (F-key bar / View menu / F9 popup) re-reads the active
   pane's directory from disk on demand.
🐛 FIX A directory whose contents changed size while its tab sat open and
   scrolled down (e.g. another process deleting/rewriting files) could
   leave the pane showing a stale blank gap with only a few rows and
   dividers rendered near the bottom — Fyne's table only clamps which row
   it starts drawing from when a scrolled listing shrinks, not the raw
   scroll position that row gets drawn at. Reload now snaps back to the
   top whenever the row count changes.

Version 0.2.0 - July 21, 2026
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✨ NEW Calculate Folder Sizes (File menu / F9 popup) — du -s-style recursive
   size for every directory in the active pane's listing (shown where the
   Size column otherwise just said "<DIR>"), plus the current directory's
   own total on the ".." row. Runs in the background with a cancelable
   progress dialog.
✨ NEW Swap Panes (Ctrl+U / popup menu) — exchange the left/right panes'
   entire tab contents at once.
✨ NEW Status bar shows the cursor item's name, size/modified time (or item
   count for a directory), plus a live selection summary.
✨ NEW Extension and Permissions columns in Full view; sorting by Extension
   breaks ties by name (ascending/descending, like every other column).
✨ NEW Favorites: a shared bookmark list plus your filesystem's volumes,
   from a ★ button in each pane. Right-click any directory to bookmark it,
   or use "Add Current Directory…" / "Manage Favorites…". Seeded on first
   run with common folders (Desktop, Downloads, and Applications on macOS).
✨ NEW External editor support for F4 — configure any number of external
   editors (name + command) and pick a default (F9 → Editors), alongside
   the built-in editor.
✨ NEW Tooltips on every button (F-key row, pane toolbar, editor toolbar).
✨ NEW About / Update-checker icons now scale to 256×256 instead of
   rendering at the source PNG's native size (was blowing the windows up
   far larger than intended); the 64×64 HardHat "ahead of the latest
   release" badge now actually has a release to compare against.
🐛 FIX Closing tabs after using "+" (new tab) could panic with an
   out-of-range slice index — DocTabs' own "+" handler was double-appending
   the new tab.
🐛 FIX Double-click / Enter didn't navigate into directories — widget.Table
   silently drops re-selecting an already-selected row, which ate the
   second click of a double-click before it was ever seen.
🐛 FIX F-keys (and Enter) stopped responding the moment any button, table
   row, or other focusable control was clicked — a real Fyne bug
   (canvas shortcuts never fire without a held modifier) meant our
   keyboard dispatch had to bypass Fyne's shortcut system entirely and
   hook raw key events instead, including inside the Table widget itself.
🐛 FIX Launching a compiled executable by double-clicking it now runs it
   directly and detached, instead of macOS's `open` wrapping it in a new
   Terminal.app window (and dying with the file manager on quit).
🐛 FIX Checking a row's selection checkbox (to multi-select before F5/F8/
   etc.) silently ate the very next F-key press until clicking elsewhere in
   the window first — same root cause as the F-key focus bug above, but for
   the checkbox specifically (it grabs keyboard focus on tap, and its own
   key handling is a no-op).
- Bumped to version 0.2.0.
